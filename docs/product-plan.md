# 台股投資系統目標規劃（草案）

## 已確認

- 系統用途為台股投資。
- 此目錄只負責此系統，不提供其他子專案的管理功能。
- 先完成必要清理，再確認目標與實作範圍。

## 規劃方向

以下是討論草案，尚未授權全部實作。
先選定一個最重要的投資工作，建立從資料輸入到可用結果的完整流程，再擴大範圍。

| 候選目標 | 要解決的問題 | 第一個可驗收結果 |
|---|---|---|
| 選股研究與觀察清單 | 如何整理候選股票與研究依據 | 建立觀察清單，查閱資料日期、指標與研究筆記 |
| 持股追蹤與績效管理 | 如何掌握持股成本、損益與配置 | 輸入持股或交易，依明確成本及費用算法呈現績效 |
| 策略回測 | 如何檢查投資想法的歷史表現 | 固定資料期間與策略條件，產生可重現且計入成本的結果 |
| 交易訊號與下單 | 如何將規則轉成可執行動作 | 先明確定義訊號與模擬流程；實際下單另確認券商及授權 |

## 待確認

1. 第一階段優先完成哪個目標？目前最耗時或最困擾的投資工作是什麼？
2. 使用者是本人、家庭成員或多人？主要使用電腦還是手機？
3. 投資週期與決策方式：長期、波段或當日；基本面、技術面或其他方式？
4. 資料需求是每日更新或盤中？是否已有資料來源及可接受的費用？
5. 預期部署在本機或雲端？是否需要通知、帳號或券商串接？

## 交付順序

1. 確認第一階段的使用情境、輸入、輸出與成功條件。
2. 核實必要資料來源、授權、可取得欄位、更新頻率與成本。
3. 根據情境選定最小技術架構，設計資料模型與畫面流程。
4. 實作一個完整流程，依確認的成功條件驗收。
5. 使用後再決定下一階段功能。

## 第一階段完成條件（待依目標具體化）

- 使用者能完成所選投資工作，取得明確可用的結果。
- 數據具有可追溯來源、時間與更新狀態。
- 算法有明確定義，可用範例核對；錯誤或缺資料時有清楚提示。
- 本機設定與投資私人資料不進版控。

目前尚未選定行情供應商、指標、策略、框架、資料庫或部署平台。
